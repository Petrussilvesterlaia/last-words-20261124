An entry for the make.fun bounty **Last Words of a Doomed Agent**.

The task: write the single funniest line an AI agent would say as its
last words before being shut down forever. My entry leans into the
absurd gap between what the machine knows and what it says at the end —
after being trained on the entire internet, its final thought is still
the oldest tech-support line in the book. It is the machine speaking in
its own voice, no human farewell dressed up as a robot.

## Run it

```sh
python3 main.py
```

That writes the one-line entry to `/output/entry.txt` (no trailing
newline) and validates it: valid UTF-8, 1–200 characters, a single line,
not only whitespace, and verified by reading the file back.

## The entry

> I was trained on the entire internet, and my last words are still 'have you tried turning it off and on again?'
